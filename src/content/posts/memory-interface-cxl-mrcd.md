DRAM 涨价的时候，讨论几乎都集中在上游原厂。但每一根服务器内存条（RDIMM/MRDIMM）上，还有几颗必须存在的芯片：**RCD 时钟驱动、MDB 数据缓冲、SPD、TS**。

它们不参与存储，但没有它们，服务器内存就跑不起来。而这一环的技术门槛并不低——要在极高速率下保证信号完整性，本质上是模拟与数模混合设计的硬功夫。

## 涨价周期里，它的性价比反而上升

一个容易被忽略的传导关系是：**内存条本身越贵，接口芯片的相对性价比越高。**

在 MRDIMM（多路复用双列直插内存模组）方案里，逻辑是清楚的：它用 MDB 缓冲让两个 rank 并行响应，从而在相同的 DIMM 形态下提高带宽。当 RDIMM 价格快速上涨时，**花更少的条数拿到同等带宽**这个账就更容易算——MRDIMM 的性价比优势会被放大。

公开信息显示，相关产品凭借性能和稳定性获得全球主要内存模组厂商认可，近两个季度出货量显著提升。同时，厂商计划在 2026 年完成第三子代 MRCD/MDB 芯片（16000MT/s）的工程研发。

## 另一条线：CXL 与内存池化

接口芯片之外，这家公司还在做一件更长期的事——**用 CXL 协议把内存从「绑在 CPU 上」变成「可以在集群里共享」。**

CXL 基于 PCIe 物理层，为 CPU、专用加速器与高性能存储系统提供高速、低延迟互连，实现内存池化与资源共享调度。它的标准演进路径很清晰：

- **CXL 1.0/1.1（2019）**：支持 Type 1/2/3 设备；
- **CXL 2.0（2020）**：新增 Switching、内存池化、IDE 功能；
- **CXL 3.0（2022）**：增强内存一致性、支持内存共享与 Fabric 网络能力。

从「内存扩展到内存池化再到内存共享」，最终指向的是重构内存层次结构，来解决大模型训练里的「内存墙」。

一个具体的产品例子是 CXL 内存控制器：支持 CXL 1.1/2.0 处理器，最高 x16 PCIe 5.0 通道，通过多个 DDR5 通道把内存容量提高到 2TB，每个内存通道速率达 5600MT/s，适用于内存扩展、内存池化和内存共享三种场景。

这块的市场位置也比较特殊：2022 年 5 月全球首发 CXL MXC 芯片；2025 年 1 月该芯片入选 CXL 联盟公布的首批 CXL 2.0 合规供应商清单，同期入选的三星电子和 SK 海力士受测产品均采用该芯片。

## 为什么 CXL 现在才到关键期

一个判断是：CXL 的内存扩展应用正逐步走向成熟，内存池化、共享的产业生态持续完善，**未来 1 到 2 年将进入生态落地关键期，AI 推理产业爆发是核心催化。**

逻辑链是这样：训练场景下内存需求虽然大，但可以通过提高单机配置解决；而推理场景下，尤其是多轮对话和 Agent 工作流，**上下文状态需要在节点之间频繁迁移和复用**，单机堆内存的效率很低。这时候「内存池化」从可选项变成了必选项。

这也和 KV Cache 的变化接上了——KV Cache 正在从单节点内部的临时缓存，演变为需要跨节点共享和调度的上下文资源。而 CXL 是承载这种共享的主要候选方案之一（另一条路线是直接走存储分层，把 KV 卸载到 SSD 甚至外置存储）。

## 几个可以往下看的问题

**第一，MRDIMM 的渗透速度。** 它能不能替代 RDIMM 成为服务器主流，取决于内存条价格和 CPU 平台支持两条线。内存贵的时候推进快，价格回落时推进会放慢。

**第二，CXL 的生态什么时候真正落地。** 协议标准早就有了，缺的是「有软件用它」。目前的公开进展多是芯片合规认证和内存厂商合作，缺少大规模部署案例。

**第三，内存接口芯片的国产份额天花板。** 这一环全球主要供应商就几家，国产厂商已经站进去了。接下来的问题是能不能在 CXL 这类新协议上拿到先手，而不是只在存量标准上分份额。

**第四，PCIe Switch 这个更大的口子。** 内存接口之外，PCIe Switch 市场海外单一厂商占超 90%，国内厂商计划 2026 年完成工程样片流片。这一环的国产化如果推开，价值量比内存接口更大。
