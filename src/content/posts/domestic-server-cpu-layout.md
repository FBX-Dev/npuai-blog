关于国产服务器 CPU，2026 年的公开信息里有一组很需要解释的数字：

- 一家厂商「以约 **15.2%** 的份额位居国产阵营首位」；
- 同一家厂商「2025 年在中国 x86 服务器市场市占率达 **88.4%**」；
- 机构预测它「2026 年国产服务器 CPU 出货份额 **52%–54%**」。

15.2%、88.4%、52%–54%，说的都是「份额」，但说的是三件不同的事：**国产阵营内部份额、x86 细分市场内份额、国产服务器 CPU 出货份额。** 分母越窄，数字越大。

这类数字不辨口径就引用，很容易得出「国产 CPU 已经拿下半壁江山」或者「国产 CPU 还不到 16%」这样互相抵消的结论。

## 格局：两超多强，各自有主场

按公开的份额梳理，国内服务器 CPU 市场已经形成比较稳定的分层：

- **海光信息**：国内唯一拥有完整 x86 永久授权的厂商，2026 年一季度营收 40.34 亿元、同比增长 68%。生态兼容是它最硬的资产——金融、电信、互联网这些存量系统庞大的领域，迁移成本最低。
- **华为鲲鹏**：基于 ARM 架构，拥有从芯片到服务器到操作系统的全栈能力。2025 年在中国服务器市场份额据报已超过 22%。
- **龙芯中科**：依托 100% 自主的 LoongArch 指令集，在自主可控要求最高的场景里地位特殊。
- **飞腾信息**：CPU 累计应用量截至 2025 年底突破 1300 万片，党政存量是主要阵地。
- **兆芯**：走 x86 兼容加 Chiplet 路线，核心数上更有弹性。

市场常被概括成「两超多强」——鲲鹏与海光构成第一梯队，合计份额在国产服务器 CPU 中超过 70%（这个数字本身就是「国产阵营内部」口径）。

## 信创市场：不同行业选了不同的架构

把信创市场拆开看，会发现各家并不是在同一个池子里竞争，而是各占一个主场：

| 应用场景 | 主要 CPU | 份额估算 | 逻辑 |
| --- | --- | --- | --- |
| 电信运营商 | 鲲鹏 | 超过 80% | ARM 生态强势，应用服务器与边缘计算 |
| 金融机构 | 海光 + 鲲鹏 | 海光 45%、鲲鹏 35% | x86 兼容需求高 |
| 政务办公 | 飞腾 + 龙芯 | 飞腾 40%、龙芯 20% | 存量替换为主 |
| 央企通用 | 兆芯 + 海光 | 兆芯 25%、海光 30% | 规格驱动 |
| 国防 / 核电 | 龙芯 | 超过 80% | 自主可控刚需 |

这些份额估算来自公开资料整理，**不是官方统计**，各机构口径差异不小，宜作结构性参考。

集采数据更能说明采购端的真实倾向。2026 年 8 月中央国家机关台式机批量集采中，六大国产 CPU 平台首次实现全覆盖，海光平台包占采购总金额的 44.8%，鲲鹏平台包居次席，两者合计占采购总量的 69.2%。中国移动在最新一轮 6.29 万台服务器招标中，ARM 架构（主要为鲲鹏）占比达 65%；其 2025 年集采首次纳入 30% 的国产 CPU 服务器，2026 年有望提升至 40%。

## 全球盘子里的另一条线：x86 在让位

国产 CPU 之外，全球服务器 CPU 的结构变化同样值得注意。按出货量口径，2026 年一季度英特尔份额 54.9%，同比下降 9.5 个百分点；AMD 27.4%，上升 3.3 个百分点；**ARM 阵营 17.7%，上升 6.2 个百分点**。

ARM 阵营的代表是 AWS Graviton、英伟达 Grace/Vera、谷歌 Axion、微软 Cobalt。英伟达 2026 年 6 月发布 Vera CPU，首批客户包括 OpenAI 和 Anthropic，黄仁勋的说法是「在 AI 智能体时代，CPU 已经成为数据中心性能的关键瓶颈」。

这句话值得单独想一下。**AI 推理和 Agent 工作负载的特点是大量串行调度、频繁工具调用**——这些恰恰是 CPU 的活儿。GPU 负责算，CPU 负责决定算什么、什么时候算。推理占比上升，CPU 的相对权重就会回升。

RISC-V 阵营目前还没有市占超 2% 的单一厂商，但 2025 年已有 7 款 RISC-V 服务器 CPU 进入公测阶段。

## 几个可以往下看的问题

**第一，AI 推理会不会真的把负载推回 CPU。** 如果 Agent 类应用成为主流，服务器 CPU 的量价都会受益。但这一层目前主要是定性判断，还缺公开的量化数据。

**第二，Chiplet 什么时候成为国产 CPU 的标配。** 单芯片核心数有物理上限，多 Die 集成是绕开先进制程限制的现实路径。兆芯已经验证过这条路，鲲鹏和龙芯是否跟进是关键观察点。

**第三，制程与产能。** 国产 CPU 主力仍集中在 7nm 节点。据公开信息，华为通过中芯 N+2 工艺实现了接近 7nm 的量产，但产能和良率仍是瓶颈。这一条直接决定了国产 CPU 能供多少货。

**第四，生态的长期成本。** 龙芯的 LoongArch 性能已经追上来，但操作系统、编译器、行业中间件的适配仍需大量投入。短期看 x86 兼容，中期看 ARM 生态，长期看自主架构——这句话概括得挺准确，但三者的时间表和投入规模都还没有公开答案。
